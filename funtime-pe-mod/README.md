# FUNTIME PE — самостоятельный Fabric-мод

Клиентский мод для Minecraft Java 1.21.4, который добавляет отдельный раздел
Bedrock/PE в сетевое меню. Мод не является аддоном ViaFabricPlus и не требует
ViaFabricPlus, ViaBedrock или другого стороннего клиента для открытия меню.

## Что уже разделено по слоям

- собственный список PE-серверов и экран редактирования;
- гостевой профиль с отдельным ником;
- отдельный экран официального Microsoft device-code входа;
- выбор режима входа для каждого сервера: `Гость` или `Microsoft`;
- собственные модели конфигурации, профиля и сессии;
- собственный каркас RakNet/Bedrock transport и пакетный codec;
- отдельные структуры для Bedrock-палитр, секций чанков и преобразования block state.

## Важное ограничение протокола

Java 1.21.4 и Bedrock — это разные сетевые протоколы и разные клиентские
модели мира. Самой кнопки недостаточно: для полноценной игры нужны RakNet,
UDP-фреймы, Bedrock login chain, encryption, compression, registry, chunks,
blocks, entities, inventory, resource packs, input и перевод этих данных в
клиентский мир Java. Этот проект сознательно не маскирует незавершённые части
под ViaFabricPlus: неподдержанный этап возвращает понятную ошибку, а не молча
открывает чужой экран.

Гостевой режим работает только на серверах, которые разрешают offline/guest
вход. Microsoft/Xbox вход обязателен там, где сервер проверяет Xbox Live.
Никнейм сам по себе не заменяет Microsoft-аутентификацию.

## Сборка

Нужны Java 21 и Gradle:

```bash
gradle build
```

Готовый мод появится в `build/libs/`. Для Fabric нужен только Fabric Loader,
Fabric API и сам мод. Локальные Via-jar из старого архива больше не участвуют в
сборке и не являются зависимостями.
